# Robotics Venue Guides — 학생을 위한 학회·저널 안내

로보틱스의 주요 학회와 저널·매거진을 설명하는 한국어 가이드 8개를 한곳에서 찾아볼 수 있는 링크 허브입니다.

## 공개 사이트

<https://gisbi-kim.github.io/robotics-venue-guides-kr/>

## 구성

- 학회: ICRA, IROS, RSS, SSRR
- 저널·매거진: T-RO, IJRR, RA-L, RAM

## 콘텐츠 경계

이 저장소에는 각 가이드의 원본 HTML을 복사하거나 병합하지 않습니다. `index.html`은 각각 독립된 GitHub Pages 사이트와 원본 저장소로 연결되는 링크만 제공합니다.

## 기술 구성

- 단일 정적 `index.html`
- 외부 프레임워크·폰트·스크립트 없음
- 데스크톱과 모바일 반응형 레이아웃
- GitHub Pages가 `main` 브랜치의 저장소 루트에서 배포

## 링크 검증

2026-08-16 기준 8개 가이드 사이트의 HTTP 200 응답과 각 저장소의 `public/main` 상태를 확인했습니다. 각 가이드의 일정·정책·인용 수는 해당 페이지에 표시된 스냅샷 시점을 따릅니다.
